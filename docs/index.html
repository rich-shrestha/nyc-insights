      How it works

      1. Collect. Every Sunday night a GitHub Action pulls question-style posts from YouTube comments, Bluesky, Stack Exchange, your Google Sheet (and Reddit once keys exist), plus a 12-month 311 summary.

      2. Tag & cluster. Each question gets a theme from config/themes.yml. Similar wording (TF-IDF cosine) is grouped into clusters.

      3. Score. Demand: engagement + times asked + distinct sources. Answerability: best match in config/datasets.yml. Freshness: how recent the asks are. Weights live in config/scoring.yml.

      Mark used. Tap "Mark used" on a card. It opens a pre-filled GitHub issue; tap Submit. A bot adds it to config/used.yml, rebuilds the site (about 2 minutes), and closes the issue. To undo, open an issue titled unuse: <id>.
